# AI Print Copilot

원하는 품질을 **말하면**, AI가 근거와 함께 설정 변경안을 제안하고, **작업자가 승인한 뒤에만** 실행하는 3D프린팅 전문가용 출력 설정 · 모델링 보조 프로토타입입니다.

인터랙션 디자인 스튜디오 「3D Printing × AI — 전문가를 위한 AI 시스템」 연구용 프로토타입 (고사무엘)

**데모:** https://okm0413-tech.github.io/Print-Copilot/ (GitHub Pages 설정 후)

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 출력 설정 패널 | Bambu Studio 좌측 패널 재설계. 상태바 칩 · 필라멘트 한 줄 · 목적 프리셋 · 쉬운 말 슬라이더(실제 수치 병기). "전문가 수치"를 켜면 Bambu Studio 세부 설정 77개(품질 · 강도 · 속도 탭, 검색) |
| 모델 · 출력 상세 | 업로드 모델 홀로그램 미리보기, 키링 파라메트릭 모델 편집 · 형상 분석 · STL 내보내기 |
| 명령 채널 | 부관 호출 입력칸(마이크 · 호출하기). 슬라이싱 유닛은 변경안 A/B + 근거, 모델링 유닛은 CAD 명령 목록 |

## 핵심 흐름

1. 대상 유닛(슬라이싱 / 모델링)을 고르고 원하는 결과를 말로 입력 — 예: "표면을 매끈하게 하되 출력시간 증가는 20% 이내로"
2. 변경안 A(추천) · B(차선책)와 변경마다 근거 한 문장, 조건 충족 / 초과 태그
3. 검토(재계산) → 명시적 승인 → 반영, 되돌리기 항상 가능. 실물 출력은 자동으로 시작하지 않음
4. 모델링: "고리 구멍 지름 4mm로, 두께 3mm로" → 명령별 미리보기 · 승인 · 거부, 명령 기록으로 되돌리기

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다. 외부 라이브러리는 STL 삼각분할용 `earcut`(jsDelivr CDN) 하나뿐입니다.

## 알아둘 점

- **AI 응답:** Claude 연동은 claude.ai 아티팩트 안에서만 동작합니다. 그 밖에서는 키워드 규칙 기반 "기본 규칙 모드"로 변경안을 만듭니다.
- **시간 · 소재 추정:** 슬라이서 연동 전이라, 입력한 슬라이서 예상값 대비 비율로 추정합니다.
- **음성 입력:** 브라우저 음성 인식(Web Speech API)과 마이크 권한이 있을 때만 동작합니다.
- **STL 내보내기:** 외곽 · 고리 구멍 · 두께만 반영합니다. 필렛 · 각인은 미리보기에만 표시합니다. STEP · 정밀 NURBS는 SMLib 연동 후 과제입니다.
- **저장:** 입력값과 기록은 보는 사람의 브라우저(localStorage)에만 저장됩니다.
